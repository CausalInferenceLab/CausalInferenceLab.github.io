라운지

데이터 실무자가 묻고, 나누고, 돌아보는 곳입니다. 인과추론이 아니어도 괜찮습니다. 글은 GitHub Discussions에 쌓이고 몇 분 뒤 여기에 보입니다.

글 올리는 기준

  • 데이터 실무라면 무엇이든. 분석, 실험, 인과추론, 데이터 엔지니어링, 커리어와 이직 이야기 모두 좋습니다.
  • 질문에는 상황을 함께. 어떤 데이터로 무엇을 하려는지, 무엇을 해 봤는지 적으면 답이 빨리 달립니다. 해결되면 도움이 된 답을 채택해 주세요.
  • 홍보는 소식 게시판에. 모집, 행사, 채용, 강의 소개는 데이터 실무자에게 쓸모 있는 내용이면 됩니다. 연락처만 남기는 광고는 내립니다.
  • 바로 내리는 글. 성인, 도박, 대출 광고는 허브에서 바로 빠지고 GitHub에서도 정리합니다.
  • 사람이 아니라 내용에. 반대 의견에는 이유를 붙여 주세요.

매월 1일, 지난달 글 가운데 한두 편을 골라 연재로 옮기고 가짜연구소 채널에 소개합니다. 내 글을 고치거나 지우는 일은 GitHub에서 합니다.
